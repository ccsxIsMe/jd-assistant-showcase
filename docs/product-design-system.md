# 全站体验规范（2026-10-27）

以原首页为视觉基准，保留深夜蓝、薄荷绿、悬浮资料卡、滚动渐现和交互式场景。首页仍是展示页面；实验室保留引导研究与大画布，岗位保留可调三栏，简历采用要求列表加材料核对区域，历史采用可筛选记录。没有把不同任务变成相同表单。

共享样式位于 `src/app/product-polish.css`：夜蓝 `#0a1120`、薄荷 `#7bf0cb`、可读深绿 `#176653`、冰蓝文字、白色卡片和浅灰工作区。薄荷用于深色背景，深绿用于白底按钮与链接；状态同时有文字和边框。统一12px面板圆角、可见焦点、按钮禁用状态、错误恢复入口。中文优先Microsoft YaHei UI，表单与正文保持可读字号，超长内容允许换行。

共享Button源码继续使用shadcn/CVA/Radix；Modal保持Esc、焦点返回与可访问名称。DemoRibbon只标识材料性质，不代替教程；教程定位真实DOM，不调用模型、不生成业务确认。主导航为首页、岗位、实验室与历史，示例和AI连接为辅助入口；简历从岗位下游进入，已有JD快捷入口在首页与 `/match`。

主操作由真实数据状态决定；待确认、已确认、锁定、待审阅和保存状态不合并。JD局部建议保持前后差异、应用、拒绝及撤销。研究模式切换仍只改变视图，完整证据板按需加载，来源和图像详情不预加载。
