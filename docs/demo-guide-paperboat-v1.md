# 纸舟活动工作室：比赛展示与重复操作指南

入口：`http://127.0.0.1:3000/examples`。本案例为 **示例项目｜虚构材料｜预置分析结果**，fixture `paperboat@1`。所有历史时间为本次实例化/实际操作时间，不伪造企业研究。展示不会调用收费模型；请求阶段、引用校验、数据存储、撤销、导入导出均运行正式业务代码。

## 故事与材料

两位运营想做活动浏览、报名、名额控制、名单查看和CSV导出，没有内部开发团队。参考产品中的支付、积分、聊天并非自己的确认需求。两份资料针对**同一首轮活动**分别要求满额候补和立即关闭，这是需人决定的真实案例内冲突。预算、技术栈和工期未知。三个不同方向为：现有服务组合（暂不新增招聘）、轻量定制Web、分阶段扩展。主线选择轻量Web，具体框架、薪资、福利和准确人数不凭空确认。

实际文件在 `public/demo/paperboat/`：reference.html为本地模拟产品页；interface.png为1000×720程序绘制图；paperboat-brief.docx及paperboat-resume.docx可真正用Mammoth解析；resume.txt便于复制。manifest.json记录文件哈希和从实际截图元素测量的区域坐标。均不冒充外网抓取或视觉模型结果。`pnpm prepare:demo`可复现资源，需要当前已安装Edge。

## 完整主线（约五至八分钟）

1. 首页“体验完整示例”进入案例中心，AI帮我规划卡点击“从头体验”。查看已经本地解析的资料，点击开始AI规划；结果清楚标注预置，不表演模型思考。
2. 展开关键证据与冲突；查看三种方案。使用“我不确定”，或保存自定义偏好，不会自动成为确认事实。自定义的新范围不能用旧预置答案重新分析，可手工继续或明确切换真实模式。
3. 选择轻量定制Web，审阅逐项要求。处理冲突或明确带着假设继续，再确认方案生成资料包。保存快照并预览导入，可取消部分要求；新岗位任务及要求全部重新待确认。
4. 在工作台逐条确认任务与要求，主动生成JD。选中段落“精简内容”，先看差异，再应用/拒绝，支持撤销。预置局部建议只覆盖精简，不解释任意新增需求。
5. 点击“用当前岗位核对简历”，无需再次粘贴JD。上传虚构简历DOCX或粘贴文本，查看隐私遮盖范围，主动确认核对。四种状态包含明确描述、描述不足、未体现和同项目时间不一致。
6. 点击引用定位原文。记录一项人工修正并重分析，修正不会消失。下载Markdown，包含模式标识、岗位标准、材料版本、来源快照及待核实问题。

## 各模块独立入口

案例中心六张卡分别进入AI规划、共同研究、证据板、岗位JD、简历核对、研究历史。每张都提供“查看完成版”和“从头体验”；两种种子各有一个当前实例，不因重复点击无限创建。完成版预设选择与确认明确记入活动记录，不表示当前操作者作了审批。从头版当前草稿未分析；历史保留两份可查看的演示快照，进入工作台后仍待确认。

自主展示：共同研究修改功能 → 切到AI规划检查修改 → 完整证据板查看双方冲突依据 → 删除关系并撤销 → 移动节点、调整图片标注 → 保存快照 → 打开旧快照只读 → 返回继续。切换不重排全图、不改变业务确认。

## 重置、个人副本和真实性

重置在案例中心明确确认，只创建指定种子的新实例，将旧示例记录标为归档，旧快照和资料仍保留。个人项目、从其他版本导入的工作区和个人副本不删除。重复打开继续当前示例，重置不是清空整个IndexedDB。复制完成版为个人项目会重绑定完整来源、节点、关系、快照、岗位和简历ID；二进制另存，不向每份快照重复塞Base64。复制仍保留虚构来源说明，旧示例不变。

修改超出预置资料、功能或简历范围，示例返回明确错误并保留编辑。真实重分析需要本地配置、主动选择真实模式和确认外部发送/计费；仅切换模式不调用。真实模型错误不切回固定答案。无音频转写、自动联网看视频、扫描件OCR或自动网页截图。

本地数据按浏览器、域名和端口隔离，清除站点数据会丢失。建议导出完整研究包及岗位备份；测试使用独立Edge临时上下文，不访问个人浏览器数据。
