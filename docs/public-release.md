代码在独立目录整理，不覆盖原项目未提交文件，不清空原浏览器资料。AI配置页面的本机绝对地址改为项目根目录 `.env.local`，相应浏览器断言同步调整；新克隆按README从空密钥模板配置mock。这些变更仅用于展示副本的可移植性。
